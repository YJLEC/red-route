# 参考网站交互观察

- 页面：https://4c-web.pages.dev/
- 访问日期：2026-08-27
- 用途：只提炼产品组织和交互原则，不复制前端、资产或视觉成品。

## 可借鉴的原则

1. 首次进入用短暂的沉浸式引导建立主题气氛，随后立即进入可操作的主导航。
2. “地域图志 / 神州沙盘 / 营造入卷”把探索、地图和内容阅读分成清楚的模式。
3. 地图选择与“当前聚焦”状态联动，用户先选择地区，再进入具体对象。
4. 对象详情先给一句概括和少量标签，再分段展开，不把全部文字挤在地图旁边。
5. 地图来源在界面中公开标注，说明地理可视化需要保留来源意识。

## 不采用的做法

1. 不复制其水墨、古建牌匾、3D 建筑或纵向文字视觉语言。
2. 不采用必须长时间滚动才能进入主功能的开场；本项目首屏必须直接可用。
3. 不复制按省份浏览古建的页面层级；本项目只覆盖河北三个目的地，应减少导航深度。
4. 不设置评论区、拼图等与游客出行决策无直接关系的功能。

## 对本项目的转化

- 首页直接显示河北目的地示意地图和当前选中的目的地摘要；
- 地图、比较、行程三个模式使用清晰的分段控制，而非隐藏在长页面中；
- 详情页首屏同时保留“为何值得去”和“如何游览”的入口；
- 景点点位、路线和侧栏必须同步高亮，并公开信息来源和核验日期。
