```text
│ 数忆红途                     [地图] [比较]       信息核验入口 │
├───────────────────────────────────┬──────────────────────────┤
│                                   │ 01 河北博物院红色展厅     │
│          河北轮廓地图              │ 城市内 · 室内 · 约2小时   │
│                                   │                          │
│      03 狼牙山                    │ 主题摘要                  │
│                                   │ [地铁] [低强度]           │
│  02 西柏坡       01 河博          │                          │
│                                   │ 主要抵达方式              │
│      城市与关系线路                │ 行前关键提醒              │
│                                   │ [查看完整导览 →]          │
├───────────────────────────────────┴──────────────────────────┤
│ 三地一眼比较：主题 / 时间 / 强度 / 空间 / 交通               │
└──────────────────────────────────────────────────────────────┘
```

地图标记切换时，右侧内容在固定区域更新，不推动地图尺寸。地图下方保留下一部分的可见提示，但首屏已经可以完成目的地选择。

```text
├──────────────────────┤
│ 01 河北博物院红色展厅 │
│ 城市内 · 室内 · 约2h  │
```

手机端不使用覆盖地图的大侧栏。地图与摘要按顺序排列，点击标记后自动把摘要标题带入可视区域，但不强制滚动整页。

## 详情页：移动端

```text
┌──────────────────────┐
│ ← 总览    数忆红途    │
│ 目的地名称            │
│ [时间] [强度] [类型]  │
├──────────────────────┤
│ 内部路线示意          │
│ 01 ━ 02 ━ [03] ━ 04  │
├──────────────────────┤
│ 当前景点              │
│ 图片占位              │
│ 说明 / 前往 / 停留    │
├──────────────────────┤
│ 抵达方式              │
│ 行前准备              │
│ 来源与核验            │
└──────────────────────┘
```

路线示意保持固定宽高比，点位文字允许换行。景点信息直接在地图后显示，不用遮挡地图的全屏底部抽屉。

## 三种详情地图差异

- 河北博物院：楼层平面风格，突出入口、上楼和四个展览单元；
- 西柏坡：纪念馆与旧址群两层关系，重点点位以院落路径连接；
- 狼牙山：纵向海拔感路线，明确山脚、登山段、纪念塔和可选支线。
